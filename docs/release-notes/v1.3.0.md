# RF Noise Map v1.3.0

The multi-radio release: the Hermes Lite 2 joins the SDRplay, each frequency slot picks its radio, and maps can space their dots evenly by distance.

- **Switching fix for the SDRplay (from real-hardware tests).** A strong signal's leftover data was making a quiet channel read up to about 55 dB too high right after a jump. The program now waits longer (about 33 ms) only when it jumps from a much stronger frequency to a weaker one, and re-reads once if a reading suddenly drops far below that channel's last level. Switch_Test.bat gained a table of wait sizes to confirm this.
- **Hermes Lite 2 support (network cable, HF only).** Several receivers run at the same time, so every frequency is read at the same instant with no retuning. No driver is needed (plain network packets). New: radio picker, Find my radio, radio gain, detail per frequency, HL2_Test.bat (found? streaming cleanly? mirrored? gain? overload?), HL2 awareness in Check setup and the full test. Tested against a simulated radio; not yet on a real one.
- **Slices view.** One small live panadapter for each frequency being measured, side by side. Shown automatically while logging; Preview slices shows it before a drive.
- **Every reading is timed to the millisecond.** The CSV now has the time of each reading and the time its position refers to (new column pos_time_utc). Old files still work.
- **Maps with one dot every X feet.** Choose the spacing when the map (or Google Earth file) is made: the program works out the distance travelled from the clock and GPS track, and keeps the strongest reading (or the average) in each stretch. The recording is never changed.
- **Up to four radios, one per frequency slot.** Tick the radios you have in the new "Your radios" box; each of the four frequency slots has a Radio choice (Auto / Hermes / SDRplay). Example: the Hermes Lite 2 holds an AM-broadcast slot and two HF ham bands (all read at the same instant), while the SDRplay does airband and 70 cm. Auto places HF on the Hermes Lite 2 and everything else on the SDRplay. The design is open for a third radio type later.
- **Easier installing (Windows).** The installer now asks about your radio FIRST: a Hermes Lite 2-only install skips the SDRplay driver, PothosSDR and the exact-Python requirement completely. If you do use the SDRplay and PothosSDR is missing, the installer can now install it for you (through winget). One line at the top says you can press Enter at every question. The control panel starts with your radios already ticked.
- **Version 1.3.0** in the panel, guide, README and story page.
- **Hear and record Hermes slices - even while driving.** Each Hermes Lite 2 slice has Listen (one at a time), a mode choice (AM, SAM, USB, LSB, NFM) and Record. Several slices can record at once, each to its own WAV (12,000 samples/s, named with slice, frequency and start time) in the Recordings folder; recordings survive even if the program is stopped mid-file. Measurements are never disturbed - the sound is read from the same stream the radio is already sending.
- **Per-slice zoom slider.** Every slice has its own zoom slider (full width to x16), centred on the measured frequency, live while sliding, remembered per slice.
