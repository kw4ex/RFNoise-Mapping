# RF Noise Map 1.2.0 (testing)

> **TESTING VERSION: UNTESTED IN THE FIELD.** This is a pre-release for testing on more computers. It has passed its self-test with practice data and on one Windows 11 PC with a real RSP1 and USB GPS, but a real drive has **not** been done yet. The **Mac version has never been tried on a real Mac.** Please tell KW4EX what works and what does not (open an issue on this page).

**Windows installer: `Install_RFNoise_Windows.bat`. Mac: `RFNoise_Mac_v1.2.0.zip`.**

**Windows is the main version** (Windows 10 and 11). A **Mac version is included but experimental and not yet tested on a real Mac** (see Assets).

Find power-line and other radio noise by driving a route: an **SDRplay** receiver and a GPS log the signal level about every 10 feet, and the program draws a street map of **blue (weak) to red (strong) dots**, so you can see where the noise is loudest.

## How to download (no GitHub account needed)

**Windows**

1. Install nothing first: the installer finds Python for you and offers to install it (Python 3.9 is used because the radio library needs that version).
2. Look at the **Assets** list at the bottom of this page and click **Install_RFNoise_Windows.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. If Windows says "Windows protected your PC", click **More info** then **Run anyway**. It asks a few short questions and installs into its own `RFNoise` subfolder (suggested: `C:\RadioScripts`).
4. At the end, say yes to the **full test**, with the radio and GPS plugged in.

**Mac (experimental)**

1. In **Assets** click **RFNoise_Mac_v1.2.0.zip**. Open Downloads and double-click it to unzip.
2. Open the **mac** folder, right-click **Install_RFNoise.command**, choose **Open**, then **Open** again.

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

The **Install and User Guide (PDF)** is attached below, and in the repository under `docs/guides`.

## New in 1.2.0
- **Installer picks the right Python:** the SDRplay radio library for Windows (PothosSDR) only works with Python 3.9; the installer detects this, uses Python 3.9 and installs it if needed. It also repairs pip.
- **Find my GPS:** finds a USB GPS puck and its speed (4800, 9600, 38400, 115200) by itself, in the window (button), in the installer, or with `Find_GPS.bat`.
- **Full test:** `Test_Everything.bat` (or the **Full test** button) checks Python, the radio (real readings and gain control), the GPS, and a pretend drive with the real radio and builds a map, in about a minute.
- **Radio and GPS busy?** Leftover RF Noise Map helpers are closed at launch. Other SDR or GPS programs (SDRuno, SDRconnect, SDR Console, HDSDR, u-center and similar) are listed in a yellow box with a button to close them; nothing is closed without your OK.
- Clearer GPS messages (port in use, wrong speed, no satellites); fixes for the radio library on Windows.
