# RFI Trail 2.0.0i (testing release)

Changes since 2.0.0a (versions b to i were tested on one Apple-silicon Mac; the Windows changes have not been tested on a Windows PC yet):

- **Mac icon fix.** The program is now started as an interactive macOS job (with a Terminal-window fallback), because macOS 27 stopped it a couple of seconds after the icon started it. The launcher also checks for an already running copy, a different version, or a stuck copy and says what it found.
- **Close the browser, close the program** (Settings checkbox, on by default). It waits a few seconds and never closes during a drive or an audio recording.
- **Phone / tablet access is on by default.** A QR box sits with the other boxes at the top; **How?** opens the instructions, **Off** turns it off, and the **Phone / tablet** button turns it back on. No restart is needed any more.
- **New phone page** (the QR code opens it): big live S-reading, Start / Stop / Mark spot, strong-signal alert on the phone (sound and vibration), a map that follows you, and the four slot panadapters on a scrolling page.
- **Picture smoothness** (Settings, and on the phone's Slots page): Normal, Light, Medium, Strong. It changes only how the slot pictures are drawn; logged readings and maps are unchanged.
- **Mac clamshell question** at start: "Allow clamshell mode?" keeps the Mac awake while the program runs (plugged in), and ends by itself when the program closes.
- New tests for all of the above.

Later fixes and additions in 2.0.0i (same version number, the download was updated):

- **Printing and saving a map.** The street pictures are waited for, and the print window shows a flat picture of the map (street pictures, dots, markers and the credit line). The first press of **Print map** now works too.
- **Mac installer.** The old SDRplay download address (a "Page Not Found") is replaced by https://www.sdrplay.com/api/. If the SDRplay software is missing, the installer says so, finishes installing RFI Trail and the icon, and you can add the SDRplay software afterwards. New installs also keep helper programs alive when RFI Trail exits.
- **Mac Restart button.** On the Mac the program runs as a macOS background job, and macOS removed the helper that was meant to start the new copy, so **Restart** only closed the program. Restart now asks macOS itself to restart the job.
- **Hermes Lite 2 on a Mac with several network connections.** The radio's data stream now uses the same network connection the radio answered on, which fixes "The radio did not send any samples".
- **Car mode** shows a blue **You are here** dot at the GPS position and centres the map on it.
- **Sound on / MUTED button** in the top bar silences every slot, the strong-signal beep and the spoken readings at once. It is shared by every open browser tab (a second tab in another browser used to keep playing).
- **Sound and Voice tick boxes** next to **Strong signal on**, so the beep and the spoken S-reading can be switched on and off from the main screen.
- **View: Compact / Normal.** Compact squeezes the top bar and the boxes so nothing drops to a new line and shows the four slots two across (pictures only). Normal gives one slot per row at full size. The choice is remembered.
- **Maps: Light grey and Dark backgrounds** now use Esri's free grey maps, because the CARTO ones started asking for an API key. Make a new map to get them.
- **Maps: power lines layer** also shows substations and transformers, picks up poles tagged as utility poles, shows pole numbers and operators, and has a **Load for this view** button to load another area.
- New tests: car "You are here", Hermes interface choice, compact view and mute, power layer.
