# RF Noise Map v1.4.0 (TESTING VERSION)

TESTING VERSION. Up to four radios, any radio in any slot: RTL-SDR dongles join the Hermes Lite 2 and the SDRplay. The dongle support was built and checked with simulated dongles only; it has **not yet been tried on real dongles**. Everything from 1.3.0 and its fixes (1.3.0a to 1.3.0h) is included.

- **RTL-SDR dongles (new, untested on real hardware).** Tick "RTL-SDR dongles" under Your radios, press Find my dongles, then pick RTL-SDR 1 to 4 in any slot's Radio chooser. Each dongle is its own receiver, so several dongles read at the same moment; each dongle has its own gain slider (0 to 49 dB, default 30). Dongles are numbered by serial number so a slot keeps its dongle after a replug (give each dongle its own serial with rtl_eeprom; the guide shows how, and Find my dongles warns when serials are shared). Below about 24 MHz the program turns on the dongle's direct-sampling mode (RTL-SDR Blog V3 HF).
- **Limits for now:** dongle slots show a live picture and record readings, but have no sound and no zoom yet. Levels from different dongles are not directly comparable.
- **Check setup** lists each dongle found.
- **Help and guide:** new RTL-SDR section with the Windows (Zadig) and Mac (Homebrew) steps, the serial-number step and hub advice; README, Mac README and story page updated.
- **Installing:** the Windows installer has no dongle question yet. If you have no SDRplay, answer yes to the SDRplay question so PothosSDR is set up, and skip the SDRplay driver page.
- **Version 1.4.0** in the panel, guide, README and story page.
