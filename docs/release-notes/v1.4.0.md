# RF Noise Map v1.4.0 (TESTING VERSION)

TESTING VERSION. Up to four radios, any radio in any slot: RTL-SDR dongles join the Hermes Lite 2 and the SDRplay. The dongle support was built and checked with simulated dongles only; it has **not yet been tried on real dongles**. Everything from 1.3.0 and its fixes (1.3.0a to 1.3.0h) is included.

> **Testing status:** some testing is done, but not all features have been confirmed as field ready. Shared as is, no warranty, use at your own risk.

- **1.4.0r (TESTING VERSION)** - ANAN read test now reads at 10.0 and 10.1 MHz and says whether the strongest peak is a real signal (same frequency both times) or made inside the radio (same offset both times).
- **1.4.0q (TESTING VERSION)** - ANAN read test: the first real reading showed a strong peak that Thetis did not show, so the analysis was unreliable. It now removes the radio's DC offset, ignores the band edges and centre, and lists the five strongest peaks with their frequencies, measured against the typical noise of the usable band.
- **1.4.0p (TESTING VERSION)** - ANAN read test fixed using the Thetis recording: the radio sends its data back to the port the request came from (the test listened on another port), and the start packets (General, DDC-Specific, High Priority) now copy what Thetis sends, with transmit drive kept at zero and PTT never set. If the plain start gets no data, the test tries a second start with silent transmit streams like Thetis. Not yet confirmed on the real radio.
- **1.4.0o (TESTING VERSION)** - The ANAN did not answer my start request (firewall rule present, nothing arrived on any port). New Tools\Capture_ANAN.bat records how Thetis starts the radio (Windows built-in pktmon, only packets to/from the radio, kept on the PC) so the program can copy it exactly.
- **1.4.0n (TESTING VERSION)** - When the ANAN read test hears nothing it now runs extra checks: is the firewall rule there, which address reaches the radio, and a listen on every port the radio might use, so the cause can be pinned down.
- **1.4.0m (TESTING VERSION)** - Fix: Allow_ANAN_Firewall.bat closed at once when started normally (it passed an empty value to PowerShell), so Windows never asked for permission. It now asks, and says what to do if no question appears.
- **1.4.0l (TESTING VERSION)** - First real ANAN read test heard nothing: the Windows Firewall blocks the radio data to Python. New Tools\Allow_ANAN_Firewall.bat adds one narrow inbound UDP rule for Python (own network only, asks Windows for permission, can be removed with the word "remove"). The read test now says this when no data comes back.
- **1.4.0k (TESTING VERSION)** - ANAN round 2: new Tools\ANAN_Read_Test.bat starts one ANAN receiver for a couple of seconds (receive only: PTT off, drive zero, amplifier off, and the radio is always told to stop) and reports packets, level and the strongest signal. Not yet usable in a drive. Tested only against a pretend ANAN so far.
- **1.4.0j (TESTING VERSION)** - First step towards the ANAN (Apache Labs, Protocol 2): **Scan for radios** now finds and identifies it (address, protocol, firmware, free or in use). Finding only: it cannot be used in a slot yet. New file anan.py with a pretend ANAN for testing. The guide now says that radios can be added any time after the install.
- **1.4.0i (TESTING VERSION)** - New Windows install layout. Everything now lives in **C:\RadioScripts\RFNoise_Mapping**: Start, Stop and Uninstall at the top, then help files (RFNoise_Help.html, PDF guide, README) and LICENSE.txt, with the test and helper files in **Tools** and their reports in **Reports**. An older **RFNoise** folder is renamed (nothing copied or deleted) and loose files are moved to Reports or Backups\old_files. New standalone Uninstall_RFNoise_Mapping.bat in the download folder. Mac is unchanged.
- **RTL-SDR dongles (new, untested on real hardware).** Tick "RTL-SDR dongles" under Your radios, press Find my dongles, then pick RTL-SDR 1 to 4 in any slot's Radio chooser. Each dongle is its own receiver, so several dongles read at the same moment; each dongle has its own gain slider (0 to 49 dB, default 30). Dongles are numbered by serial number so a slot keeps its dongle after a replug (give each dongle its own serial with rtl_eeprom; the guide shows how, and Find my dongles warns when serials are shared). Below about 24 MHz the program turns on the dongle's direct-sampling mode (RTL-SDR Blog V3 HF).
- **Limits for now:** dongle slots show a live picture and record readings, but have no sound and no zoom yet. Levels from different dongles are not directly comparable.
- **Check setup** lists each dongle found.
- **Help and guide:** new RTL-SDR section with the Windows (Zadig) and Mac (Homebrew) steps, the serial-number step and hub advice; README, Mac README and story page updated.
- **Installing:** the Windows installer has no dongle question yet. If you have no SDRplay, answer yes to the SDRplay question so PothosSDR is set up, and skip the SDRplay driver page.
- **Version 1.4.0** in the panel, guide, README and story page.
- **1.4.0a**: two new columns at the end of every drive file, **slot** (the panel slot number 1-4, kept even when a slot above it is off) and **radio** (hl2, sdrplay, rtl1-rtl4), so the data of one slot or one radio can be isolated in later processing. Older drive files and the map maker work as before.
- **1.4.0b**: five improvements from the First Drive.
  - **Drive bar:** the route name, Practice, Start / Stop, Pause / Resume, Apply frequency changes, Map when I stop, a live status (dots and speed) and the new Quick map button now sit in a bar under the title that stays in view. Start errors show right under it. Jump links go to Setup, Live slots, Drives and Maps.
  - **Quick map:** one press maps the drive being recorded (what is saved so far) or your newest drive, with all slots and your chosen dot spacing.
  - **Only use some of the readings:** the map and Google Earth can be limited by slot, radio, frequency, speed range and level range (for example slots 1, 3 and 4 without slot 2). The map title and file name say what it was limited to. Older drives are sorted into slots by their frequency order.
  - **Flat channels:** map colours never use less than 10 dB, and a channel that moved under 6 dB is marked FLAT, so a quiet channel no longer looks like a rainbow.
  - **Same place, several frequencies:** the map lists places where two or more frequencies rose together (with how many passes saw them) and can ring them on the map.
  - **Settings saved with each drive:** the info file now holds the program version, the gains, the Hermes detail setting, the dot spacing, the slot-to-radio list and any gain or slot change made during the drive; the drives list shows the gains. The drives list also counts dots by position (621 for the First Drive, not 2185).
- **1.4.0c**: the operator's controls.
  - **Speed in large type** in the drive bar, with the **real dot spacing at this speed** (for example "10 ft set, about 33 ft at 45 mph") and a warning with the speed that would keep your spacing when the radio cannot keep up. Spacing buttons 5 / 10 / 20 / 50 in the bar.
  - **Health strip:** GPS light with satellites, time since the last dot, radio overload warning, and time, miles, dots and marks for this drive. An **alarm** (beeps, red flashing bar) sounds if the GPS goes quiet or no dots are saved for 8 seconds while moving.
  - **Mark spot** (button or the M key, with an optional note): a flag at your current position, saved with the drive and shown on the live track and on the finished map.
  - **Noise tone:** an optional beep that rises in pitch when a chosen slot climbs 4, 6 or 10 dB above its own recent level.
  - **Live track:** the dots appear on a street map while you drive, coloured like the finished map, with Follow me.
  - **Car mode:** large buttons and numbers for the passenger seat (Start / Stop, Pause, Mark, speed, spacing, health, live track).
  - The speed shown is now live (it used to update only when a dot was saved). The logger status also reports the time one round of readings takes.
- **1.4.0d**: map options.
  - **Ten backgrounds** (pick one, remembered): Street, Satellite, Satellite + street names, Terrain (OpenTopoMap), Topo (Esri), USGS imagery and topo (US), Light grey, Dark, and No background (works offline).
  - **Switches you can flip any time:** Dots, Heat glow, Marked spots, **Power lines & poles** (from OpenStreetMap), and **Also show** a second frequency as rings. A **see-through** slider for the dots.
  - **Replay the drive:** the dots appear in recorded order at 10x to 300x, with a slider.
  - **Street View, Navigate and Apple Maps links** in the pop-up of every dot, flag, ring, hot-spot circle and pole.
- **1.4.0e**: hardware window, S-units and the speed test.
  - **Bigger top bar** (A- / A+ to change) with an always-visible **hardware line**: GPS fix, satellites and coordinates; the radio and frequency of every slot; and the **max speed** for your dot spacing. The big speed row now shows only while recording (it was always showing).
  - **Hardware setup window** (separate from the drive screen): live **GPS** (fix, satellites, HDOP, position, speed), **Radios** (tick and Scan for radios), **Slots** (any radio to any slot, with frequency and calibration). The radio and GPS settings moved here from box 1.
  - **Test my setup:** records a few seconds (nothing kept), checks GPS and every slot, times one round of readings and gives the **fastest speed you can drive for each dot spacing**; the figure stays in the top bar and goes live while you record.
  - **S-units next to every dB value** (slot readouts, readings table, live track, map pop-ups / legend / hottest spots, Google Earth export) and a new `level_s` column in the drive file. Calculations stay in dB. S9 = -73 dBm up to 30 MHz, -93 dBm above; 6 dB per S-unit. Shown as ~S7 until the slot is calibrated; **Calibrate** button (type -73 or S9) in the Hardware window.
  - **Map: Flag high noise**: red rings on every reading at or above a chosen S-level.
  - **Radio plug-in layout** (`radio_plugins.py`): one small class per radio type. Planned types (ANAN, FlexRadio, TCI, CAT radios) are listed greyed out; they are not built yet.
- **1.4.0f**: bigger controls, four slot boxes, S-meters.
- **1.4.0g**: the four S-meters can be resized together by dragging a corner grip, and a "Side by side (4 across)" option puts them in one row. Size is remembered.
- **1.4.0h**: a **Highest** meter in the top bar (strongest reading of the active slots, each round, with its slot); a **Warning** box with sound chooser, volume and an S-level slider; a **Show meters** on/off switch for the four big meters; "Fastest safe speed" renamed **Max speed**; hardware line laid out as a proper grid; duplicate Hardware setup button removed.
  - The **top control row** (Start / Stop, Pause, Mark spot and the rest) is much larger; Hardware setup and Test my setup moved into it.
  - The hardware line is now **four defined slot boxes** (no more wrapping), each with the **live S-unit and dB reading** of that slot.
  - **Fixed-width level and S-unit columns** everywhere (slot readouts, readings table, summary boxes, meters): nothing jumps when a value changes length.
  - **Four large analog-style S-meters**, one per slot: needle = latest sample cycle (refreshed once per cycle while recording), orange marker = highest reading since the drive started, with a Reset peaks button.
