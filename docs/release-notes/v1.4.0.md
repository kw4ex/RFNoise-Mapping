# RF Noise Map v1.4.0 (TESTING VERSION)

TESTING VERSION. Up to four radios, any radio in any slot: RTL-SDR dongles join the Hermes Lite 2 and the SDRplay. The dongle support was built and checked with simulated dongles only; it has **not yet been tried on real dongles**. Everything from 1.3.0 and its fixes (1.3.0a to 1.3.0h) is included.

- **RTL-SDR dongles (new, untested on real hardware).** Tick "RTL-SDR dongles" under Your radios, press Find my dongles, then pick RTL-SDR 1 to 4 in any slot's Radio chooser. Each dongle is its own receiver, so several dongles read at the same moment; each dongle has its own gain slider (0 to 49 dB, default 30). Dongles are numbered by serial number so a slot keeps its dongle after a replug (give each dongle its own serial with rtl_eeprom; the guide shows how, and Find my dongles warns when serials are shared). Below about 24 MHz the program turns on the dongle's direct-sampling mode (RTL-SDR Blog V3 HF).
- **Limits for now:** dongle slots show a live picture and record readings, but have no sound and no zoom yet. Levels from different dongles are not directly comparable.
- **Check setup** lists each dongle found.
- **Help and guide:** new RTL-SDR section with the Windows (Zadig) and Mac (Homebrew) steps, the serial-number step and hub advice; README, Mac README and story page updated.
- **Installing:** the Windows installer has no dongle question yet. If you have no SDRplay, answer yes to the SDRplay question so PothosSDR is set up, and skip the SDRplay driver page.
- **Version 1.4.0** in the panel, guide, README and story page.
- **1.4.0a**: two new columns at the end of every drive file, **slot** (the panel slot number 1-4, kept even when a slot above it is off) and **radio** (hl2, sdrplay, rtl1-rtl4), so the data of one slot or one radio can be isolated in later processing. Older drive files and the map maker work as before.
- **1.4.0b**: five improvements from the First Drive.
  - **Drive bar:** the route name, Practice, Start / Stop, Pause / Resume, Apply frequency changes, Map when I stop, a live status (dots and speed) and the new Quick map button now sit in a bar under the title that stays in view. Start errors show right under it. Jump links go to Setup, Live slots, Drives and Maps.
  - **Quick map:** one press maps the drive being recorded (what is saved so far) or your newest drive, with all slots and your chosen dot spacing.
  - **Only use some of the readings:** the map and Google Earth can be limited by slot, radio, frequency, speed range and level range (for example slots 1, 3 and 4 without slot 2). The map title and file name say what it was limited to. Older drives are sorted into slots by their frequency order.
  - **Flat channels:** map colours never use less than 10 dB, and a channel that moved under 6 dB is marked FLAT, so a quiet channel no longer looks like a rainbow.
  - **Same place, several frequencies:** the map lists places where two or more frequencies rose together (with how many passes saw them) and can ring them on the map.
  - **Settings saved with each drive:** the info file now holds the program version, the gains, the Hermes detail setting, the dot spacing, the slot-to-radio list and any gain or slot change made during the drive; the drives list shows the gains. The drives list also counts dots by position (621 for the First Drive, not 2185).
