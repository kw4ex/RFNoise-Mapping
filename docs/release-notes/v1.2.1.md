# RF Noise Map 1.2.1 (testing)

> **TESTING VERSION: UNTESTED IN THE FIELD.** This is a pre-release for testing on more computers. It has passed its self-test with practice data and on one Windows 11 PC with a real RSP1 and USB GPS, but a real drive has **not** been done yet. The **Mac version has been installed on one MacBook (Apple silicon) but has not been used with a radio or on a drive.** Please tell KW4EX what works and what does not (open an issue on this page).

**Windows installer: `Install_RFNoise_Windows.bat`. Mac: `RFNoise_Mac_v1.2.1.zip`.**

**Windows is the main version** (Windows 10 and 11). The Mac version is experimental.

## How to download (no GitHub account needed)

**Windows:** under **Assets** at the bottom of this page, click **Install_RFNoise_Windows.bat**, then double-click it from your Downloads folder. If Windows says "Windows protected your PC", click **More info** then **Run anyway**.

**Mac:** under **Assets** click **RFNoise_Mac_v1.2.1.zip**, double-click it in Downloads to unzip, open the **mac** folder, right-click **Install_RFNoise.command**, choose **Open**, then **Open** again. If macOS says it "cannot be opened because Apple cannot check it", click Done, then open System Settings > Privacy & Security, scroll down, click **Open Anyway** and enter your Mac password.

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

The **Install and User Guide (PDF)** is attached below.

## New in 1.2.1 (found by installing on a MacBook)
- **Mac installer: Homebrew fixed for Apple-silicon Macs.** An older Intel-type Homebrew in `/usr/local` made every install fail with "not writable". The installer now uses the correct Homebrew (`/opt/homebrew`), offers to install it, and offers a one-command fix if Homebrew cannot write to its folders. It also checks that the tools really installed before building the radio driver, and says clearly what to do if not.
- **Mac data folder moved out of Documents.** macOS blocks programs started from the desktop icon from reading Documents, which made the panel blank. Your data now lives in a folder named **RF Noise Map** in your home folder (earlier data and settings are copied over automatically).
- **Mac desktop icon now starts the program in native (Apple-silicon) mode.** The icon could be started under Rosetta, where the radio-math library (numpy) could not load and the panel showed errors.
- **Mac "Apple cannot check it" warning:** the guide, the Mac readme and these notes now explain the exact clicks (Privacy & Security > Open Anyway), and the installer clears the warning for the other files in the unzipped folder, so the uninstaller opens normally.
- **Installer closes a running RF Noise Map first**, so a reinstall never shows the old program.
- **New installer check:** at the end of the Mac install it starts the control panel and checks that it answers and can read your data folder, and tells you in plain words if macOS is blocking it.
- **Control panel no longer goes blank:** if one part cannot load (for example macOS blocking the Documents folder), a red message now says what is wrong and the rest still works. The Full test and Check setup buttons no longer fail when no GPS choice is selected.
- **Radio driver build fixed on Macs with incomplete Command Line Tools:** the installer now finds the compiler headers inside the Mac SDK, so the SDRplay driver module builds instead of stopping with "cstring file not found".
- **Progress message on slow buttons:** any button that takes more than half a second (Full test, Make map, Backup, Start logging and so on) now shows a blue banner saying what the program is doing, with a seconds counter.
- **Mac radio driver link fixed:** the installer re-points the SDRplay driver module at the SDRplay library that is actually installed on the Mac.

**No warranty. Use at your own risk.** Shared by one radio operator, "as is". Design and on-air testing by KW4EX. Not made, approved or supported by SDRplay, Elecraft, FlexRadio, Thetis or Zeus.
- **New: Panadapter.** A live spectrum and waterfall of a band, with a built-in receiver (AM, USB, LSB, CW, narrow FM, selectable bandwidth). Click a signal to listen to it, and press a button to use it as one of your 4 mapping frequencies. UNTESTED on a real radio at this point.
- **Watch a band while logging:** the panadapter picture (spectrum and waterfall) works while a drive is being recorded, for any one of your frequencies. Picture only: you cannot tune or listen while logging.
- **Dot spacing is now easy to find and can be changed while driving,** with quick buttons (5, 10, 20, 50, 100 ft).
- **Panadapter handling:** drag the picture (or swipe sideways on a trackpad) to move the view; a typed tune frequency that is off screen re-centres the view; the Up/Down keys and the arrows in the Tuned box now follow the chosen step.
- **Signal level meter moved** to the Squelch row, just above the panadapter picture.
- **Attenuation is yours to choose.** The IF and RF attenuation boxes under the panadapter are the same settings recording uses, and can be changed while driving (a warning notes that earlier and later dots are then not directly comparable). Automatic gain is for listening only, is off by default, and is never used while recording, so it cannot change recorded values.
- **Panadapter readability:** the frequency numbers along the picture (and the dB and audio labels) are larger, bold and brighter. "Width of view" is now a slider (narrow to wide) with the current width shown beside its name.
- **Live level column:** the frequency list now has a "Level now (dB)" column that shows the latest reading for each frequency (with a colour bar) and updates as the drive is recorded. It shows a dash when not logging.
- **Panadapter: 1 Hz tuning step** (the display now shows frequencies to 1 Hz).
- **Panadapter: VFO lock.** A big green/red button locks the tuned frequency so it cannot be changed by accident.
- **Panadapter: memory frequencies** that tune, set the mode and centre the picture; save your own, delete any. A starter list is included.
- **Panadapter: audio recording.** Record what you hear to small universal WAV files (8 kHz mu-law, about 29 MB per hour) kept in a Recordings folder, with Play, Save a copy, Show in folder and Delete.
- **Panadapter bands:** CB (channels 1-40) added to Jump to band. New tick box "Widen the view to show the whole band" sets the Width of view so the whole chosen band fits.
- **Panadapter markers:** yellow labels on the picture for the 40 CB channels, WWV/CHU time stations, NOAA weather, ham calling and beacon frequencies, airband, marine and FRS/GMRS. Click a label to tune it (suitable mode and bandwidth) and centre the picture on it. Show/hide all markers or each group with tick boxes.
- **Mac desktop icon no longer shows "not responding" when the program is already running.** The icon now starts the program in the background and finishes at once. If a copy is already running it asks: open the running one, close it and start fresh, or cancel.
- **Quit also closes the browser tab** (Mac: Safari, Chrome, Edge, Brave, Arc). The first time, macOS may ask to allow RF Noise Map to control the browser; click OK.
- **Reading by time or distance.** New choice next to Dot spacing: take a reading every X feet (the default) or every X seconds, even when standing still. Useful for catching an intermittent noise at one spot. It can be changed while logging.
- **Logs for diagnosis.** Every install writes a log that is kept (newest 10) in the Logs folder; the program writes runtime problems to Logs/program_errors.log (panel, logger, panadapter and browser errors). Tools card: Show recent problems, Open the logs folder, Make a support file (one zip with the logs and PC details; the GPS key is left out).
- **Smarter installers (Mac and Windows).** A quick check of the computer first; a problem finder that explains the likely cause, the fix and a web page for the most common failures (no internet, pip/SSL blocks, missing tools, access denied, full disk, missing runtime, driver and radio-library mismatches); an offer to make a support zip when something fails; a summary of warnings at the end.
- **Existing install menu.** Running the installer again offers upgrade/repair, a health check with support file (changes nothing), or uninstall.
- **Windows package completed.** Start menu entries, an entry in Windows Settings > Apps, new Make_Support_File.bat and Open_Logs.bat, Recordings and Logs folders, a /silent switch (`/silent /dir=PATH`, `/silent /uninstall`), and a new uninstaller with an inventory, three options (program only, program plus data after a backup zip, everything), removal of all shortcuts and the Apps entry, and a log that survives.
- **Mac uninstaller** has the same three options and a backup zip.
- **Panadapter: SAM mode** (synchronous AM) for stations that sound distorted in plain AM.
- **Panadapter: FM broadcast** band (88-108 MHz) and a wide-FM mode (mono, with 75 microsecond de-emphasis).
- **Panadapter: Left/Right arrow keys** tune down/up by the chosen step (Shift = ten steps).
- **Attenuation: Reset to defaults** button (IF 40 dB, RF 0) in More settings and under the panadapter.
- **Quieter radio check.** PothosSDR's harmless "no VOLK config file found" note is no longer shown by the installers or the radio library.
- **Full test fixes.** The gain-control check now uses your strongest channel (a quiet channel near the radio's own noise cannot show a change), and a browser closing or reloading the page is no longer written to the error log as a problem.
