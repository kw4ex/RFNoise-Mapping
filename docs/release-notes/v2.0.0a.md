# RFI Trail 2.0.0a (testing release)

A small update to 2.0.0, in the same download names with an "a". Same program, same data folders.

## Fixed
- **Slot numbers no longer shift.** When a slot could not be used (for example 148 MHz set to the ANAN, which cannot hear it), the slots after it were drawn in the wrong panel, so slot 3 could show slot 4's signal and slot 4 said "Waiting for the radio...". Each reading now stays with its own slot, the skipped slot says why, and the sound, record and live-picture buttons follow the right slot.
- **Windows installer: the firewall step** no longer leaves a second window waiting for a key press. The installer now waits for the firewall helper, says "Firewall step finished", and carries on. If Windows permission is declined, it says so and goes on.
- **Old name removed** from the installer and uninstaller banners ("Noise Trail" became "RFI Trail").

## New
- **Sound: AGC and volume** in Settings: **Volume with AGC off**, **AGC strength** and **AGC recovery speed**, with a button to put the defaults back. They apply to every slot, work at once and are remembered.

Tested: new automatic tests for slot numbering, the sound settings and the Settings screen; the Windows installer changes are checked by reading only and still need a real run on Windows.
