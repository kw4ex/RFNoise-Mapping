# RF Noise Map v1.5.0

The ANAN release. Everything from 1.4.0 and its fixes (1.4.0a to 1.4.0za) is included.

> **Status:** shared as is, no warranty, use at your own risk. Tested with simulated hardware and on a Windows 11 PC and a Mac with a real SDRplay RSP1, a real Hermes Lite 2, a real ANAN-7000DLE MkIII and a GPS. Not yet confirmed in a long real drive with every radio, and the RTL-SDR dongle support has only been tried with simulated dongles. Design and on-air testing by KW4EX.

- **ANAN support (Apache Labs, OpenHPSDR Protocol 2, for example the ANAN-7000DLE MkIII).** Tick **ANAN** under Your radios and pick it in a slot's Radio chooser. Up to four slots are read at the same instant, on the main antenna input, like the Hermes Lite 2. Receive only: PTT is never set, the transmit drive level is zero, and the radio is told to stop when the program stops. Checked on the real radio against WWV (5, 10 and 15 MHz) and a shortwave broadcast station. The ANAN hears up to about 55 MHz. **Limits for now:** levels are in dBFS (not yet dBm), no sound from an ANAN slot, no gain control, no calibration. Close Thetis first: one program at a time can use the radio.
- **Finding the ANAN.** **Scan for radios** shows its address, firmware and whether another program is using it.
- **Windows firewall helper.** `Tools\Allow_ANAN_Firewall.bat` adds one narrow inbound rule for Python (your own network only, asks Windows for permission, `remove` takes it away again). Only needed if ANAN data does not arrive.
- **Slots no longer lock up.** A slot set to a radio that cannot hear its frequency (the ANAN above 55 MHz, the Hermes Lite 2 above 38 MHz) is turned down at once with a message; the old setting stays and the slot keeps working. The slot message no longer says "tick a radio" when only the ANAN or RTL-SDR is ticked.
- **Windows install layout** (from 1.4.0i): everything in `C:\RadioScripts\RFNoise_Mapping`, with `Tools` and `Reports` folders; an older `RFNoise` folder is renamed, nothing deleted. Leftover ANAN test files from test builds are moved out of the way when you upgrade.
- **Version 1.5.0** in the panel, guide, README and story page.
