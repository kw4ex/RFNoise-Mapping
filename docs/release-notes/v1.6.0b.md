# RF Noise Map v1.6.0b

Fixes to v1.6.0 for the ANAN radio and the slot view. No new features. Everything in v1.6.0 is included.

> **Status:** shared as is, no warranty, use at your own risk. Tested with simulated hardware and on a Windows 11 PC and a Mac with a real SDRplay RSP1, a real Hermes Lite 2, a real ANAN-7000DLE MkIII and a GPS. The ANAN slots were confirmed working on the Mac with this build.

## What is fixed

- **One radio that is missing no longer stops the others (1.6.0a).** In the live view, a radio that cannot be opened (for example a Hermes that is not plugged in) now only turns off its own slots, and each of those slots says why. Before, the whole live view failed and an ANAN that was found never connected. Recording a drive is as strict as before.
- **The ANAN is now chosen automatically (1.6.0a).** A slot whose Radio is left on automatic now picks the Hermes first, then the ANAN, then the SDRplay. The ANAN also shows its name in the Hardware setup bars and the map filters.
- **A slot set to Hermes no longer quietly uses the ANAN (1.6.0b).** Only a real Hermes Lite 2 counts as a Hermes now. If only an ANAN is on the network, the slot says so and tells you to set its Radio to ANAN.
- **The side-by-side (2 across) slot view is back (1.6.0b).** A Full-size choice remembered by the browser from an older version is cleared once. The **Compact view** option in Settings remembers your choice after that.

## Known open item

- **ANAN levels are not yet calibrated to true dBm**, so S-meter readings on ANAN slots can read higher than another receiver. Until this is fixed, use **Hardware setup > Calibrate to a known signal** on each ANAN slot.
