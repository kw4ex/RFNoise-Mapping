# RFI Trail 2.0.0

**RF Noise Map is now RFI Trail.** This is the successor program: same purpose (find power-line and other radio noise by driving a route), new name, and a lot more underneath.

> **Status:** a testing release, shared as is, no warranty, use at your own risk. Tested on Windows 11 and an Apple-silicon Mac with a real ANAN-7000DLE MkIII and FLEX-6700. RTL-SDR dongles and CAT radios are tested only against simulated radios.

## New in 2.0.0 (compared with RF Noise Map 1.6.0b)

- **Radios are plug-ins**: ANAN, FlexRadio 6000/8000, CAT radios (Icom, Yaesu, Kenwood, Elecraft) in Follow or Control mode, next to SDRplay, Hermes Lite 2 and RTL-SDR dongles. Each slot picks its own radio; unused radios are never opened or checked.
- **Hardware setup** window: scan, status line, "Ready to drive?" check, hides radios that were not found, saved setups, calibration colours, FlexRadio "not found" help.
- **Context help** everywhere (press ? or F1), including the map pages.
- **Practice mode banner**: a red banner whenever the pretend radios are on.
- **Better listening**: AGC Fast/Medium/Slow work in real seconds with a quick recovery and a soft limiter; AGC Off is louder.
- **Clearer messages**: a radio that cannot be opened names the slot that needed it. Bolder, larger status boxes.
- **Windows installer rebuilt**: own private Python, offers the firewall helper for network radios, keeps a copy of the download, brings data over from "Noise Trail". **Mac installer** brings data over too.
- **Guide as PDF and HTML** in every download.
- **Security tightening**: the control panel and its helper only answer this computer; map pop-ups show text from notes and OpenStreetMap as plain text; oversized requests are refused.
- **Credit**: With thanks to Jeff Stuparits, W4DD, whose noise-mapping program and help inspired this one.

## Upgrading from RF Noise Map or "Noise Trail"

RFI Trail installs into its own folder (`RFI_Trail` on Windows, `RFI Trail` on the Mac) and does not touch RF Noise Map. If you used the earlier test version called "Noise Trail", the installer offers to bring your drives, maps and settings across.
