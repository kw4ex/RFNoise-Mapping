1. What you need

  • A computer in the car: a Mac or a Windows 10/11 PC (laptop). It runs the program and does the logging.
  • A radio (one or several), with an antenna mounted away from the engine:
    • an SDRplay RSP1 on a USB cable (covers VHF, airband, 70 cm and the FM band), and/or
    • a Hermes Lite 2 on a network cable (HF only, about 0.1–38 MHz; several receivers at once, no driver needed), and/or
    • an ANAN (network cable, four receivers at once) or a FlexRadio 6000/8000 (network), no driver needed, and/or
    • RTL-SDR dongles (USB), or an Icom / Yaesu / Kenwood / Elecraft radio on a CAT cable (see “Newer tools” below).
  • A GPS, either:
    • your iPhone with the GPS2IP app (simple; one position per second), or
    • a USB GPS plugged into the computer. A 10-updates-per-second model gives much closer dot spacing at 40–45 mph.
  • The iPhone's Personal Hotspot is handy for internet in the car (needed only to draw the street background when you view a map, and for iPhone GPS).
Why not the iPhone as the whole system? The SDRplay needs a computer driver; it cannot run on an iPhone or iPad. The phone is only the GPS and the hotspot.

2. Download and install

RFI Trail comes as one download for each kind of computer. Each one is a zip file with a short START_HERE.txt inside. No account is needed, and nothing is sent anywhere.

  • Mac: RFI_Trail_Mac_v2.0.0.zip (the folder of the same name is the unzipped copy)
  • Windows 10 / 11: RFI_Trail_Windows_v2.0.0.zip
The installer works as an update too: run the newer package's installer and it replaces the program and keeps your drives, maps, recordings and settings.

Mac

  1. Open Downloads. If you have the zip, double-click it to unzip it. Keep the folders mac and app together, side by side.
  2. Open the mac folder. Right-click Install_RFI_Trail.command and choose Open, then Open again. (Only the first time. macOS asks because the file came from the internet.)
  3. Type 1 and Return for Install or update. A window explains each step before it does it. Press y and Return to go on.
  4. When it says DONE, a RFI Trail icon is on your Desktop and in Applications.
If macOS says "cannot be opened because Apple cannot check it for malicious software" (normal for a downloaded file): click Done (never "Move to Trash"). Then either (a) right-click the file, choose Open, then Open again; or (b) open System Settings → Privacy & Security, scroll down to the message about the file, click Open Anyway and enter your Mac password. You only need to do this for the installer; it then clears the warning for the other files in the folder (including the uninstaller).
If the file opens in a text editor, or says it cannot run: open Terminal, type bash (with a space), drag the install file into the Terminal window, press Return.

The installer menu also offers 2) Check my setup and make a support file (changes nothing) and 3) Uninstall. Your data lives in the RFI Trail folder in your home folder, apart from the program (Applications / RFI Trail).

Windows 10 / 11

  1. Right-click the zip and choose Extract All. Keep Install_RFI_Trail_Windows.bat and the app folder together, side by side.
  2. Double-click Install_RFI_Trail_Windows.bat. If Windows says "Windows protected your PC", click More info then Run anyway.
  3. It explains each step and asks short questions (answer Y or n; Enter alone means yes). No administrator password is needed.
  4. Step 1 asks which folder to use. Press Enter to accept C:\RadioScripts, or type another. The program makes its own subfolder, RFI_Trail, inside it, so everything lives in C:\RadioScripts\RFI_Trail.
  5. It finds Python 3, or offers to install it for you (through Windows' own winget; the internet is needed). Then it makes a private Python for the program and downloads two small helper libraries, numpy and pyserial.
  6. When it says DONE, start the program with the RFI Trail icon on your Desktop, or Start_RFI_Trail.bat in that folder. It opens in your web browser (Google Chrome is best for sound).
What is in the Windows folder: Start_RFI_Trail.bat, Stop_RFI_Trail.bat and Uninstall_RFI_Trail.bat; README_RFI_Trail.txt and LICENSE.txt; the guide as RFI_Trail_User_Guide.pdf (to print) and RFI_Trail_Help.html; the program in app (the previous version is kept in app_previous after an update); the private Python in venv; and your data in Drives, Maps, Exports, Backups, Settings, Recordings and Logs. The install log is Logs\install_log.txt; while the program runs, problems are written to Logs\program_errors.log. In the window, Settings → Show recent problems shows them and Make a support file packs everything into one zip for KW4EX.

3. The radio driver (SDRplay only)

A Hermes Lite 2 needs none of this — it has no driver at all. Skip to section 6 if that is your radio. The SDRplay driver is not mine to include; it comes from sdrplay.com. Without it, Practice mode and all map features still work, and you can make maps from drives recorded on another computer.

Mac

  1. Run the installer again and answer y at STEP 3. It opens the SDRplay page; download the macOS API installer and run it. Restart the Mac.
  2. Run the installer once more and answer y at STEP 3. It installs the helper tools (it will offer to install Homebrew, a standard Mac tool installer; it asks for your Mac password) and builds the SDRplay driver module.
  3. Newer driver modules need SDRplay API 3.15 or later. If the build fails, update the API from sdrplay.com and try again.

Windows

  1. SDRplay driver: run the installer again and answer y at the radio step (or go to sdrplay.com → Downloads → Windows) and install the API. Restart if it asks.
  2. Radio library: the program also needs PothosSDR, a free Windows bundle (download link on github.com/pothosware/PothosSDR/wiki). Install it with the default choices.
  3. Open RFI Trail, plug in the SDRplay, and press Settings… then Health check (near the bottom of the window).
  4. Python version: PothosSDR's Python part is made for ONE Python version (currently Python 3.9). The installer notices this, uses (or installs) the matching Python by itself, and sets up the launcher files to use it. If you install PothosSDR later, run the installer again so it picks the right Python.
  5. Close other SDR programs (SDRuno, SDRconnect, SDR Console, HDSDR ...) before you start: only one program can use the radio at a time. RFI Trail shows a yellow box with a Close them for me button if it sees one.
  6. For a complete automatic check, press Full test in the Settings window. It takes about a minute and tests the radio, the GPS and a pretend drive.
Press Settings… then Health check (near the bottom of the window) any time. It says in plain English what is working and what is missing.

4. First try (no hardware)

The red PRACTICE MODE banner. Whenever Practice is ticked, a striped red banner appears across the top of the page and the browser tab says [PRACTICE]. In Practice mode the radios, the GPS and the sound are pretend, so the readings, pictures and the spike on a slot are not real. The tick is remembered between runs, so if you start the program and see the banner, press Turn practice off (or untick Practice) before a real drive. You cannot turn it off while a drive is being recorded.
  1. Open RFI Trail (double-click the icon). A window opens in your web browser.
  2. Press Try a practice drive + map in the Settings… window (under Tests, backup and help). A fake drive is recorded in a second and a map opens: a red stretch is a pretend noisy power pole.
  3. Or tick Practice in the bar at the top and press Start logging to watch the live readings for about 40 seconds.

The practice route is made up, so it won't follow real streets. Real drives will.

5. Connect the GPS

The GPS choice (iPhone or USB), and a live display of the fix, satellites and position, are in the Hardware setup window (button at the top right of the page). The top bar also always shows the GPS: a light, the satellites and your coordinates.

Option A: iPhone

  1. On the iPhone, install GPS2IP from the App Store. A free GPS2IP Lite lets you try it; the full version (a few dollars) is the one to use.
  2. Turn on Personal Hotspot on the iPhone (Settings → Personal Hotspot). Join the computer to that Wi-Fi.
  3. Open GPS2IP and switch it on. Use the fastest update rate (1 second). Make sure the Sockets option is on. Leave the app open.
  4. The app shows an address and a port. In RFI Trail choose iPhone and type them in. (172.20.10.1 and 11123 are the usual values.)
  5. Press Settings… then Health check (near the bottom of the window), tick Also listen to the GPS, and look for a green ✓ with your position.
The iPhone updates once per second. At 45 mph that is about 66 ft between true GPS fixes, so the program slides the position forward along your direction of travel. This works well on straight roads and is less exact in sharp turns.

Option B: USB GPS

  1. Plug it into the computer. In RFI Trail choose USB GPS and press Find my GPS. It listens on every likely COM port at the common speeds (4800, 9600, 38400, 115200) and fills in the right Port and Speed for you. Many pucks use 4800, not 9600.
  2. If it says the port is in use, another program has it open: close other GPS or mapping programs, or unplug the puck for 5 seconds and plug it back in. A new puck often needs a few minutes outdoors for its first position fix.
  3. Press Settings… then Health check (near the bottom of the window), tick Also listen to the GPS, and look for a green ✓.
  4. Most pucks come set to 1 update per second. For about 10 ft spacing at 45 mph you want one set to 10 updates per second (a one-time setting). Ask Claude and we'll do it together.

6. Collect data

  1. In box 1 Collect data, type a Route name (optional, but it makes drives easy to find).
  2. Choose the GPS (iPhone or USB) in Hardware setup, unless you're in Practice mode.
  3. Enter up to four frequencies in MHz. Suggestions: 0.75 (AM broadcast band, wide area), 3.7 or 7.3 (ham bands), and a VHF channel such as 148 or an AM airband channel (118–137) for pinpointing.
    • Pick a quiet channel with no station on it. A pilot's transmission on an airband channel would look like a hot spot.
    • Width is the slice measured (5–10 kHz is good). Narrow slices ignore nearby stations.
    • Leave Calibration at 0 unless you've calibrated (section 10).
  4. Dot spacing sets how often a reading is saved (default one every 10 ft). Use the quick buttons or type a number. You can change it while driving; it applies from the next dot. Smaller spacing gives more detail but bigger files, and if you drive faster than the radio can measure, dots end up farther apart than the setting.
  5. Take a reading by time instead of distance. Next to Dot spacing, choose by time and type the seconds (for example 5). The program then saves a reading every few seconds, even when you stand still — handy for catching an intermittent noise at one spot. The default is by distance. You can switch while driving; readings taken at one place pile up on one dot on the map.
  6. Press ▶ Start logging in the drive bar at the top of the page (it stays in view as you scroll; type the route name there first if you like). The header shows Logging and GPS: OK, and the big numbers show the live level for each frequency.
  7. Drive the route. Steady speed is best. You can change frequencies while driving: edit the boxes and press Apply frequency changes in the drive bar. Pause recording / Resume is there too, for stops.
  8. Press ■ Stop logging in the drive bar when finished. If Map when I stop is ticked, the map opens.
The drive bar. The strip under the title is always in view. Top row: Route name, Practice, Start logging (which becomes Stop logging), Pause recording, Apply frequency changes, 🚩 Mark spot with a note box, then Map when I stop, ⚡ Quick map, Drives & maps… (opens a window with your recorded drives, the choices for a map and the maps you have made), Car mode. Any problem starting a drive shows right under the bar; Jump to links (when not logging) take you to Setup, Live slots, Drives and Maps.
While logging, a second row appears:
  • Speed in large type, from the GPS.
  • Dot spacing: the spacing you set and what you are really getting at this speed, for example 10 ft set · ≈ 33 ft at 45 mph. The program times how long one round of readings takes; if that is too slow for your speed it says so and gives the speed that would keep your spacing (Slow to about 13 mph to keep 10 ft). “Last dots” is the measured gap between the most recent dots. The 5 / 10 / 20 / 50 buttons change the spacing on the spot.
  • Health: a GPS light with the satellite count (green good, amber weak or slow, red silent or no fix), the time since the last dot, and a RADIO OVERLOAD warning.
  • This drive: time, miles, dots and marks so far.
  • Sound. Alarm (on by default) sounds a two-tone beep and flashes a red bar if the GPS goes quiet or no new dots are saved for 8 seconds while you are moving (standing still or paused never alarms). Noise tone (off by default) gives a short beep each time the chosen slot climbs a set number of dB (4, 6 or 10) above its own recent level; the higher the rise, the higher the pitch. Your eyes stay on the road and your ears tell you when to slow down. Click anywhere on the page once so the browser allows sound.
Mark spot (or press the M key) drops a flag at your current position and keeps it with the drive; type a few words in the note box first if you like (“buzzing pole”). Flags show on the live track and on the finished map, with the note when you tap one. Live track (a box that appears at the top while logging) draws the dots on a street map as you drive, coloured like the final map: pick the slot to colour by; Follow me keeps the map centred. You can see which streets you have covered and where the red is building. Car mode hides everything except Start / Stop, Pause, Mark, speed, spacing, health, the sound choices and the live track, in large type for a passenger; press Exit car mode to return (or open the page with ?view=car added).
Good habits: don't change attenuation mid-route (dots before and after would not be directly comparable); keep the computer plugged in (the program keeps it awake while logging); drive each important road twice, once in each direction; note the date and conditions in Name / notes.
Safety: have a passenger operate the computer, or set everything up while parked. Please don't use the screen while driving.

The four slots: a panadapter for each of your frequencies

Each of your four frequencies is a slot, and each slot is a full panadapter: a big spectrum (signal strength across a slice of the band) with a scrolling waterfall underneath (signals coming and going over time). The slots are stacked one under the other; scroll down to see them all, or switch to the Compact view in Settings to fit all four on one screen. Pop out opens one slot in its own browser tab, as big as you like.

  1. Choose a radio for the slot. Top right of each slot, Radio lists Off (skip this slot) and every radio you have set up (SDRplay, Hermes Lite 2, ANAN, RTL-SDR dongles, FlexRadio, CAT radios). You can use one, two, three or all four slots: picking a radio switches a slot on (a starting frequency is filled in for you), and Off switches it off but remembers its settings. The same choice is in the Readings and frequencies table in box 1; both change together at once.
  2. Hermes slots are always live: the Hermes Lite 2 reads all of its receivers at the same instant. SDRplay slots share one tuner, so only one SDRplay slot can be Live at a time. Press the Live button on an SDRplay slot to make it the live one. The lowest-numbered SDRplay slot is live until you choose, and your choice is remembered. The other SDRplay slots keep all their settings and show their last picture, marked “not live”, until you press their Live button.
  3. Tune: type a frequency, use the − and + buttons or the mouse wheel (the Step goes from 100 Hz to 1 MHz), or click a signal on the picture. Left and Right arrow keys tune the slot you last touched (hold Shift for ten steps). Jump to band tunes the slot to a band (this includes CB). Lock stops the frequency changing by accident (clicks, wheel, keys, memories and band jumps); you can still change everything else. The slot's frequency is the frequency that is measured and mapped, so tuning a slot changes what the drive records.
  4. Mode and filter: Hermes slots offer AM, SAM, USB, LSB and narrow FM. SDRplay slots also offer CW and broadcast FM. SAM (“synchronous AM”) locks onto the carrier and often sounds cleaner on a fading or slightly mistuned station. The Filter list sets the receive bandwidth (the green band on the picture). The yellow stripe is the part that is measured (the Width box).
  5. Band view (SDRplay slots): Centre is the middle of the picture and can differ from the tuned frequency. Width of view is how much spectrum you see (250 kHz to 8 MHz). The ◀ ▶ buttons slide the view, Centre on tuned puts the tuned frequency in the middle, and you can also drag the picture left or right to slide it. Tick whole band on jump to have Jump to band choose the width so the whole band fits (bands wider than 8 MHz show their middle part). The grey edges of an SDRplay picture are less accurate. Hermes slots show the radio’s own window (96, 192 or 384 kHz around the tuned frequency, set by Detail per frequency); their Zoom slider magnifies it.
  6. The dB scale: Auto scale keeps the noise floor and the strongest signal in view. To set it by hand, drag the dB numbers at the left of the picture up or down (the wheel there stretches the scale; double-click them to go back to automatic).
  7. Listen: raise the volume slider above 0 to hear a slot; tick Mute to silence it without losing the volume. Any number of slots can play at once (the live SDRplay slot and any Hermes slots). Squelch silences the sound when the signal is weaker than the setting (far left = off). The small picture under the controls, what you hear, shows the sound spectrum. AGC (Hermes only): Off keeps the background noise at its true level next to the signals (best for hunting noise); Slow, Medium and Fast level the volume. ● Record saves what you hear to a small WAV file (see Audio recordings below). A Hermes slot keeps recording while you drive; sound from the SDRplay cannot be listened to or recorded while logging.
  8. Gain: the Hermes has one Gain slider for the whole radio (the Hermes slots move together). The SDRplay has IF attenuation (20–59 dB) and RF attenuation (0–27) sliders, a Reset button (IF 40, RF 0) and Auto gain (listening only). These are the same settings used for recording, which always uses fixed gain: switch Auto gain off when measuring. A red OVERLOAD message on a Hermes slot means a strong signal is overloading the radio; lower the gain.
  9. Controls that do not apply are hidden. A slot only shows what its radio can do: the Hermes has no IF/RF attenuators, auto gain, centre/width controls or CW/broadcast FM, and the SDRplay has no AGC choice or zoom.
  10. Known-frequency markers: small yellow labels on the pictures mark the 40 CB channels, time stations (WWV, CHU), NOAA weather, ham calling and beacon frequencies, airband and marine channels and FRS/GMRS. Click a label to tune that slot to it with a suitable mode. Use the tick boxes in the Markers and memory frequencies box (under the slots) to hide the groups you do not want. Labels that would overlap are skipped until you zoom in.
  11. Memory frequencies: shared by all four slots. Click one to tune the slot you last touched, with its mode and filter. To add your own, tune a slot, type an optional name in that slot and press Save this frequency. Delete one with the × in the Markers and memory frequencies box. A starter list (WWV, CHU, weather, airband and others) is included.
  12. Remembered: each slot remembers its frequency, mode, width, radio, zoom, centre and width of view, scale, filter, AGC, volume, squelch and lock between visits.

While you are logging: Hermes slots stay fully live. An SDRplay slot has to retune for each reading, so while mapping it shows its latest reading and a small history line instead of a picture; the live picture comes back the moment you pause or stop. Pause recording stops the dots (at a traffic light, say) and brings every slot back to full life; press it again to carry on. Pause automatically (box 1) does this by itself when you have not moved for a number of seconds (10 by default) and resumes when you move. Free the radios for other programs (in Settings) lets another program use the radio; Start live view, above the slots, brings it back.

The level shown is dBFS, not calibrated. It is good for comparing places, not for absolute measurements. Recording always uses fixed gain, never automatic gain, so the picture shows what is recorded.

Hardware setup, S-units and Max speed test

The things you set once before driving have their own window, so they stay out of the way while you map. Press Hardware setup at the top (or in the drive bar). Close it with Close this window; nothing is lost.

Adding a radio later, and the ANAN. You do not have to decide everything during the install. Open Hardware setup at any time and press Scan for radios: network radios (Hermes Lite 2, ANAN) need no driver and are found straight away. A GPS puck is found with Find my GPS. Only the SDRplay needs its driver and PothosSDR installed first; after installing them, run the installer again and choose Upgrade or repair. The ANAN (Apache Labs, Protocol 2 firmware, for example the ANAN-7000DLE MkIII) is found and identified by the scan (address, firmware, and whether another program such as Thetis is using it). Tick ANAN under Your radios and pick it in a slot's Radio chooser. It reads up to four slots at the same instant, all on its main antenna input, and it never transmits (PTT off, drive zero, and the radio is told to stop when you stop). Close Thetis first: one program at a time can use the radio. Levels are shown in dBFS, not yet calibrated to dBm, and you can listen to and record an ANAN slot like a Hermes slot (volume, Mute, Record; AM, SAM, USB, LSB, NFM; AGC and Zoom as on the Hermes). The ANAN hears up to about 55 MHz; a frequency above that is turned down with a message. If nothing arrives, run Allow_ANAN_Firewall.bat (in the Tools folder) once: it adds one Windows Firewall rule for Python, for your own network only, after you approve it. If the scan does not find the radio, check the cable and power, and that it has its Protocol 2 firmware.

  1. GPS: the fix, the satellites (with HDOP), your position and speed, kept up to date. Choose iPhone or USB and press Find my GPS here. The program listens to the GPS while it is not recording; the moment you press Start it lets go so the recording can use it.
  2. Radios: tick the radios you have and press Scan for radios. Every radio type the program knows is listed with what it found. FlexRadio and Icom / Yaesu / Kenwood / Elecraft radios on a CAT cable are supported (see the section below); only TCI radios are still planned and shown greyed out. They are built as separate small “plug-ins”, so each new radio is added without changing the screens.
  3. Slots: any radio can be given to any slot, with its frequency and calibration, right here. A change applies at once, also while recording. A radio with one receiver can only listen to one frequency at a time, so its slots take turns.
  4. Max speed test (press Settings… at the top, then Max speed test near the bottom): records for a few seconds (nothing is kept), checks the GPS and every slot, times one round of readings, and works out how fast you can drive and still get a dot at each spacing. The number stays in the top bar: Max speed for 10 ft dots: 42 mph. While you record it shows the live figure and turns red if you go faster. In Practice mode the radios are pretend, so run the test again with the real ones.

The top bar

The bar under the title is larger now: press A− or A+ to make it smaller or larger. Under the speed and health numbers is a hardware line that is always in view: the GPS (fix, satellites, coordinates), the radio and frequency of each slot, and the max speed. The big speed row appears while you record.

Meters and the alert. Each slot now shows its own S-meter at the lower right of the slot (switch them off with the S-meters tick box in Settings; each meter has its own Reset peak button). In the top bar the Strong signal box has on, GPS, the At level and Test; press ⚙ Sound & voice for the sound, volume, speaking the reading and saying S every X seconds (the button reads Voice on while either voice setting is on).

Settings and the slots. Slots open in Compact view. Under each picture are the Tune row (frequency, step and mode) and the sound row (speaker icon). The padlock beside Pop out locks the slot’s frequency. Under the Tune row you also see Filter and AGC; the sound row has the volume slider, a Mute button (it reads Listen while muted), Squelch and Record; Zoom is at the top of the slot, beside Pop out. The last line has Band (jump to a band), Width (the kHz that is measured and logged), Auto scale, and the Gain, Memory and (SDRplay only) Band view buttons. Each of those three opens a small box over the slot with only its own controls; Close shuts it. The Settings… button at the top opens one window with your radios, the GPS, how often to take a reading (every so many feet, or every so many seconds), pause when stopped, and the gain settings. Esc closes it.

Restart. The Restart button at the top, beside Close program, saves any drive being recorded, closes the program and starts it again; a new browser tab opens by itself after about 10 seconds. Use it after changing radios or when something looks stuck.

Where the slot controls are. Under each slot’s picture, the Tune row has the frequency (type it, or use − and +), the Step of each click and the Mode. The sound row below it (speaker icon) has the volume slider (above 0 you hear the slot), a Mute tick box and Record for that slot’s audio. Any number of slots can play at once.

Four slot boxes and the S-meters

The control row at the top is much larger. Under the speed and health numbers the hardware line is now four fixed boxes, one per slot, between the GPS box and the fastest-safe-speed box. Each slot box shows the radio, the frequency and the live S-unit and dB reading of that slot. The numbers have fixed columns, so they no longer jump when a value gets longer or shorter. Hardware setup and Max speed test are buttons in the top control row.

Below the bar are four large S-meters, one per slot, in the style of an amateur radio meter (S1 to S9, then +20, +40, +60 in red). The needle shows the reading from the latest sample cycle (it moves once per cycle while you record), and the orange marker holds the highest reading taken since the drive started. Under each meter are the S-unit, the dB value and the peak. Each meter's Reset peak button starts its peak marker over; all of them also reset each time you press Start. When you are not recording, the meters follow the slots' live views.

Resizing the S-meters. Drag the small grip in the bottom-right corner of any meter: all four get bigger or smaller together. Tick Side by side (4 across) to put all four in one row sized to fit the window. Reset size goes back to the standard size. The size is remembered on that computer.

Highest meter, Strong signal alert, voice and Show meters . In the hardware line at the top, next to Max speed, a small meter called Highest shows the strongest S-reading of your active slots in each round of readings, and which slot it came from (the orange marker is the highest since the drive started). Readings are compared in S-units, so a 3.9 MHz slot and a 148 MHz slot are compared fairly. Next to it is the Strong signal box: tick on to hear a sound whenever the highest reading reaches the S-level set by the Alert at slider (Off, S1 to S9, then S9+10 up to S9+60). Choose the sound (Beep, Double beep, Siren, Chirp, Bell, Low buzz), press Test to hear it, and set the Volume. The alert plays while you are recording and also while the slots are live. Tick Speak it and the program also says only the reading, for example “S, 9 plus 20”, with a short pause after the S Under Say S every type a number of seconds (0 = off) and the program says the highest S-reading out loud at that interval during a drive (“S 7”), so you know it is working without looking at the screen. The voice is your browser’s own, and uses the Volume slider; Test speaks a sample. Click anywhere on the page once after opening it, or the browser may keep sounds quiet. GPS is the older alarm that beeps if the GPS is lost or no dots are saved; it keeps its own fixed sound. Max speed is only the top speed your radios can keep up with at the chosen dot spacing: it does not know the road, traffic or the speed limit. The four big meters can be switched off with Show meters above them.

S-units

Next to every dB value the program also shows the S-unit (S1 to S9, then S9+10, S9+20 and so on): in the slot readouts, the readings table, the live track, and on the map (pop-ups, legend, hottest spots, and the Google Earth export). All calculations stay in dB, which has finer steps; S-units are only a friendlier way to read the same number. The scale is the usual amateur one: 6 dB per S-unit; S9 = −73 dBm up to 30 MHz and −93 dBm above 30 MHz. The saved drive file has an extra level_s column.

S-units are only right when the slot is calibrated (the radio's reading is a true dBm). Until then they show with a ~ in front (for example ~S7), a rough guide. To calibrate: in Hardware setup → Slots, feed the slot a signal of known strength, type its true level (like -73 or S9) and press Calibrate. The program works out the Calibration number for you.

On the map, Flag high noise draws a bold red ring on every reading at or above the S-level you choose (S5, S7, S9, S9+10 and up), so the noisiest places stand out.

Newer tools: help key, car mode, noise tone, setups and more radios

Help on any item: the ? key

You do not have to remember what everything does. Point at any button, box or number and press the ? key (or F1). A box opens that explains it. Press Esc, or click anywhere else, to close it.

  • The ? Help button (bottom right of the page) switches on help mode: click anything and it is explained instead of being pressed. Press Esc to leave help mode.
  • Inside a text box, ? just types a question mark. Press F1 there to get that box's explanation.
  • It works on the main page and on every map page, including maps you made long ago. On a map, point at the frequency list, the colour range, the layers, the hot-spot list, the replay controls and so on.
  • An item with no written explanation shows its own tooltip text instead. The full written guide (this page) is the Help & guide button at the top.

Hardware setup helpers

  • Status line. At the top of the Hardware setup window, four chips show the GPS, the radios chosen, how many slots have a frequency and whether you are recording (green = fine, amber = worth a look, red = fix it).
  • Ready to drive? One press checks the GPS, radios, slots, calibration and the Max speed test and lists anything missing in plain words. It only looks; it changes nothing.
  • Radios not found are hidden. After a scan, radio types that were not found (and are not ticked) are tucked away so you only see your real radios. Show all radio types brings them back, for example to add one that is switched off.
  • Slots table. The text is larger, and a State column shows Calibrated (green), Not calibrated yet (amber) or Slot is off (grey).
  • Saved setups. Save the radios, GPS and slots as they are now under a name (for example ANAN 4 slots) with Save current setup as.... Choose one in the list and press Load to switch (the page reloads; not possible while recording). Delete removes one. The same name replaces the old setup.

FlexRadio and radios on a CAT cable

Besides the SDRplay, Hermes Lite 2, ANAN and RTL-SDR dongles, Hardware setup now supports:

  • FlexRadio 6000 / 8000 series. It connects over the network (no USB cable), like the ANAN. Press Add a FlexRadio: the program listens for it for a few seconds and fills in its address (or type the address SmartSDR shows, then press Test). In Control mode the program makes its own receiver and spectrum picture for each slot and tunes it; in Follow mode it only reads a receiver SmartSDR already has open and never changes the radio. Allow RFI Trail / Python through the firewall (meter readings arrive by UDP). If the radio is not found, the tile says so and what to check.
  • Icom, Yaesu, Kenwood and Elecraft radios on a USB serial (CAT) cable. Add them under Radios on a CAT cable. They report the radio's own S-meter reading, one frequency at a time (a level only, no picture). Follow never changes the radio; Control lets the program tune it.
  • Scan and set up for me looks at what is really connected, forgets radios that are not there, adds those that are, ticks the right types and moves any slot that used a missing radio to Auto.
FlexRadio and CAT-radio support is new. Audio (listening, recording) and filter controls are not available for these slots yet. Please report anything that does not work.

Car mode

Press Car mode in the drive bar for a simple screen meant for the passenger seat: big Start, Pause and Mark buttons, a large speed, the status boxes (dot spacing, health, this drive, GPS, max speed, Highest signal, strong-signal alert) in large bold type, and the live map. Press Exit car mode to return. Safety: let a passenger use it.

Noise tone

The Noise tone box in the drive bar plays a short beep when a slot's reading jumps well above its own usual level, so you can hear a noise source arrive without looking. For each dot saved, the program compares each slot's newest reading with the middle value of that slot's recent history. If the rise is at least the size you chose (4, 6 or 10 dB) it beeps; the bigger the rise, the higher the pitch.

  • Slot: All (the default) watches all four running slots and beeps for the biggest rise among them. Choose 1 to 4 to watch just one slot.
  • It needs about 12 readings to learn the usual level, and beeps at most once per saved dot, so it is quiet when you are stopped.
  • Ticking the box plays a test beep so you can set the volume.

Bigger, bolder text

The top bar, the drive bar, the status boxes, the slots, Settings, Hardware setup and the map pages use larger, bolder type for reading at a glance. A− and A+ change the size of the bar under the title. Maps made with older versions are shown with the same larger text.

7. Where your data is stored

Everything you create is in one folder: on a Mac, the RFI Trail folder in your home folder (not inside Documents: macOS blocks programs from Documents); on Windows, the install folder itself (normally C:\RadioScripts\RFI_Trail). The window's footer shows its exact path, and Open my data folder opens it.

FolderWhat is in it

Each row: time, latitude, longitude, speed, frequency, level, and the slot number (1–4, as on the panel) and the radio that read it (hl2, sdrplay, rtl1–rtl4), so one slot or one radio can be picked out later. The program itself is kept apart from your data (Mac: Applications / RFI Trail; Windows: the app folder inside RFI_Trail), so you can reinstall or update it without touching your data.

Your radios, and which radio measures which frequency

The Hardware setup window (button at the top) has a Radios section. Tick what you have — one radio or several:

  • SDRplay RSP1 (USB): one receiver, so its frequencies take turns. Covers VHF, airband, 70 cm and the FM band.
  • Hermes Lite 2 (network cable): several receivers that run at the same time, so its frequencies are all read at the same instant with no retuning. HF only (about 0.1–38 MHz).

When both are ticked, the frequency table shows a Radio column, and each of the four slots picks its radio. Auto (the default) puts everything the Hermes Lite 2 can hear on the Hermes Lite 2 and the rest on the SDRplay. Or choose yourself — for example the Hermes Lite 2 on an AM broadcast channel and two HF ham bands, with the SDRplay on airband and 70 cm. A slot's radio cannot change in the middle of a drive, so the dots on each frequency always come from one radio and stay comparable.

  1. Plug the radio's network cable into the computer (or its network adapter), connect the antenna and 12 V power, and wait about 20 seconds.
  2. Close Thetis, SDR Console or any other program that uses the radio.
  3. Tick Hermes Lite 2, press Find my radio. It says where it found it. If not, type the radio's address (for example 192.168.1.50) in the box and press it again.
  4. Detail per frequency: 96 kHz is a good choice. Higher numbers use more of the network cable.
  5. Radio gain (More settings): start at +15 dB; many antennas hear best at +20 to +30 dB (the Hermes Lite 2 designers suggest +12 to +24, and a quiet antenna may need more because the radio’s own noise is lowest when its input stage has gain). If a slot shows OVERLOAD, lower it with the Gain slider in any Hermes slot. Two tick boxes sit beside the slider: Auto gain (listening only) lowers the gain by 3 dB when a strong signal overloads the radio and raises it 1 dB after 30 quiet seconds (never above +36); Gain per band (on by default) remembers the gain you set for each band and puts it back when the first Hermes slot moves to that band. You can still move the slider any time, and the newest setting is remembered. Both stop while recording, so a drive is always measured at one fixed gain.
  6. Hermes picture (in Settings): Smooth, Normal or Light sets how often the Hermes pictures refresh. It is one setting for the whole radio, changes while the program runs and is remembered. Choose Light on a slow computer or slow network.
  7. Press HL2_Test.bat (Windows, in the Tools folder) once to check the radio, the cable and the gain. Send its report if anything is wrong.
On a Mac: the network port for the Hermes Lite 2. Most Macs have no network socket, so the radio goes into a USB-to-Ethernet adapter (or a dock with an Ethernet socket). The Mac then has two network connections at once: Wi-Fi for the internet and the adapter for the radio. This is fine; leave Wi-Fi on. The program looks for the radio out of every network port, one after the other. Steps:
  1. Plug the adapter into the Mac, the Hermes Lite 2's network cable into the adapter, then power the radio. Wait about 30 seconds.
  2. Open System Settings → Network. The adapter is listed (for example USB 10/100/1000 LAN or Ethernet) with a green dot. Click it. With the radio connected directly (no router), the Mac gives itself an address that starts with 169.254. That is normal and is what we want: do not type an address by hand; keep Configure IPv4 on Using DHCP. (A message such as “self-assigned IP address” is not an error.)
  3. Do not put the radio on the Wi-Fi side or set the adapter as “Off”. Leave Wi-Fi connected as it is. You do not need to drag the adapter above Wi-Fi in the service order, and the Mac does not need to share its internet with the radio.
  4. If macOS asks whether the program may find and connect to devices on your local network, press Allow. (If you pressed Don’t Allow by mistake: System Settings → Privacy & Security → Local Network, switch the program, Terminal or Python on.)
  5. In the program tick Hermes Lite 2 and press Find my radio. It says which port it found the radio on. If it does not: check the green dot again, wait another 30 seconds, then press the button again. As a last step type the radio’s address (the 169.254… number shown in the radio’s own setup, or found by the button once) into the address box.
  6. If the Mac firewall is on (System Settings → Network → Firewall), allow incoming connections for the program or Python when asked. Radio data comes in as many small UDP packets.
Only one program can use the radio at a time: close Thetis or SDR Console on the Mac first. A radio that is still sending to another program does not answer a second program’s search.

RTL-SDR dongles (not yet tried on real dongles)

An RTL-SDR dongle (for example the RTL-SDR Blog V3) is a small, low-priced USB radio. You can plug in up to four. Each dongle is one receiver that works on its own, so several dongles read at the same moment, and any dongle can serve any of the four slots (even two slots on one dongle, which then take turns). Because this part is new and was built without real dongles, treat it as a testing feature and tell us what you find.

  1. Drivers (once).
    Windows: the radio library PothosSDR already contains the RTL-SDR driver. If you have no SDRplay, run the installer and answer yes to the SDRplay question so it sets up PothosSDR and Python 3.9, then skip the SDRplay driver page. Then give each dongle its USB driver with the free tool Zadig (zadig.akeo.ie): plug in one dongle, open Zadig, choose Options → List All Devices, pick the entry that reads Bulk-In, Interface (Interface 0) (never your keyboard or mouse), make sure WinUSB is shown, press Replace Driver, wait for the message, and repeat for each dongle. This changes only that dongle.
    Mac: open Terminal and run brew install soapysdr soapyrtlsdr (needs Homebrew, which the Mac installer can set up). No driver swap is needed.
  2. In the program, under Radios in Hardware setup, tick RTL-SDR dongles and press Find my dongles. It lists the dongles it sees as RTL-SDR 1, 2, … in order of their serial numbers.
  3. Give each dongle its own serial number (one minute each). New dongles often all carry the same number, so the computer cannot tell them apart and the slots could swap after a replug. With only one dongle plugged in, open a command window (Windows: the bin folder of PothosSDR; Mac: Terminal) and type rtl_eeprom -s 00000001, answer y, unplug and replug. Do the next dongle with 00000002, and so on. Find my dongles warns you while two dongles still share a number.
  4. In any slot's Radio chooser pick RTL-SDR 1 to 4. The slot shows a live picture of about 2 MHz around the frequency, with a Gain slider for that dongle (0–49 dB, start at 30; higher hears weaker signals but overloads sooner). Each dongle has its own gain.
  5. HF with the V3: below about 24 MHz the program switches the dongle into its direct sampling mode by itself (the V3’s HF input). HF is weaker than VHF on these dongles; leave the V3’s bias tee off unless your antenna needs power.
Good to know. Use a powered USB hub for more than one dongle, keep the hub and its cables away from the antennas (ferrite beads on the cables help), and expect a little radio noise from the hub itself. Dongle slots show pictures and record readings, but have no sound and no zoom yet. Levels from different dongles are not directly comparable (different gain), so compare a place only with readings from the same slot. With four dongles streaming together, test a short drive at home first.
Slots 1–4. The slots are described in full in The four slots above. In short: each frequency is a full panadapter with a waterfall; pick Off, Hermes or SDRplay for each; one SDRplay slot is Live at a time; Hermes slots have sound and WAV recording even while you drive.

8. Make, view, print, save and email maps

Make a map

  1. In box 2 Your recorded drives, press Make map on a drive. The map opens in a new browser tab.
  2. To combine several drives on one map, tick them and press Make map from ticked drives.
  3. ⚡ Quick map (in the drive bar and in box 2) is the one-press version: it maps the drive being recorded right now (what is saved so far, even while you drive) or else your newest drive, with all slots and the dot spacing chosen under the drives list. Nothing else to choose.
  4. Only use some of the readings. Under the dot-spacing choice, the box Only use some of the readings lets you leave things out of the map: untick a slot (for example keep slots 1, 3 and 4 and leave out slot 2), a radio, or a frequency, or set a speed range (a minimum of 3 mph drops the readings taken while you were stopped) or a level range in dB. The choices follow the drives you tick (all drives if none is ticked) and apply to Make map and Google Earth. The map title says what it was limited to, and the file name carries a tag (for example _slot134) so it never overwrites the full map. Drives recorded before slots were saved are sorted into slots by the order of their frequencies.
  5. How many dots? Every reading is saved with its time to the millisecond, so the program can work out how far you travelled at every moment. Under the drives list, choose One dot every [50] feet to space the dots evenly when the map is made, whatever your speed was. Keep the strongest reading in each stretch (best for hunting noise: a short burst is never lost) or the average. The original recording is never changed, so you can make the same drive again with a different spacing.

Read the map

  • Blue dots = weak, red dots = strong. The color bar shows the dB numbers; change Min / Max to stretch the colors, or press Auto.
  • Pick the frequency in the drop-down. Each frequency has its own picture of the same route.
  • Flat channels. The colours are stretched over the range of each frequency, but never over less than 10 dB. A frequency that moved less than 6 dB in the whole drive is marked FLAT: nothing stands out there, so a few dB of wobble does not look like a hot spot. (Flat can also mean the radio could not hear below its own noise: try more gain.)
  • Same place, several frequencies (box at top right). A noise source such as a bad insulator usually raises more than one frequency at once. The program looks for places within about 150 ft where two or more frequencies rose well above their usual level at the same time, and lists them best first, with how much each rose and how many passes saw it. Tick mark them on the map to see a dashed ring at each; tap an entry to zoom there. A place seen on two passes is a strong lead.
  • Background and what to show (panel at top left). Background picks one: Street, Satellite, Satellite + street names, Terrain (contour lines and hills), Topo, USGS imagery / topo (US only), Light grey or Dark (the dots stand out best on these, and they print cleanly) or No background (works with no internet). The program remembers your choice. Below it, tick or untick any time: Dots, Heat glow (soft glowing areas instead of single dots), Marked spots, and Power lines & poles (drawn from OpenStreetMap: tall lines in orange, smaller lines dashed, poles and towers as yellow dots; coverage varies, so a missing pole on the map is not proof there is none; needs internet). Also show draws a second frequency as coloured rings around the dots, so you can compare two frequencies on the same road. See-through makes the dots fainter so the road or photo shows underneath.
  • Replay the drive. Open Replay the drive, press play, and the dots appear in the order they were recorded (pick 10× to 300× speed); drag the slider to jump to any moment. Slide fully right for the normal view.
  • Finding the source. Tap any dot, flag, ring or pole: the pop-up has Street View (what that spot looks like from the road), Navigate (Google Maps directions) and Apple Maps links, so you can see the pole or house and drive straight to it.
  • 🚩 Flags are the spots you marked while driving; tap one for its note and time.
  • Tap a dot to see its level, time and speed. Hottest spots lists the ten strongest places; tap one to zoom there.
  • The button at top right switches Street / Satellite. Zoom in to separate dots.

What is saved with each drive

Besides the readings (CSV), each drive has a small info file (.meta.json) holding its name and notes, the program version, the gains (Hermes, SDRplay IF/RF, RTL-SDR), the Hermes detail setting, the dot spacing, the slot-to-radio list, and a time-stamped note of any gain or slot change made during the drive. The drives list shows the gains under each drive name, so you can always tell what a map was recorded with.

Print or save as a PDF

In box 3 Maps press Print / PDF (or the Print / Save as PDF button on the map itself). The print preview shows the title, color scale, strongest spots and the map. Choose your printer, or Save as PDF as the destination. Landscape paper works best.

Save a viewable file

Each map is already a file in Maps folder of your data folder (section 7). Save a copy downloads another copy anywhere you like. Double-click it any time to view it again. It needs internet only for the street background.

Email a map

  1. Press Email beside the map. Type an address (optional) and keep Put the map in a .zip ticked (many email systems block .html attachments).
  2. Press Create email. Your email program opens with the file attached; check it and press Send.
  3. If your email program can't be controlled automatically (some web-based or newer mail apps), a blank email opens and the file is shown in a folder: drag it into the email. The person receiving it unzips it and opens the map in any browser.

Other extras

  • Google Earth: Google Earth beside a drive creates a .kml file with the colored dots (in Exports). Open it with Google Earth.
  • Spreadsheet: Save CSV gives the raw data for Excel / Numbers.
  • Name / notes: add a name and notes (weather, antenna, what you were looking for).
  • Back up everything: one zip of Drives, Maps and Exports in the Backups folder.
  • iPhone / iPad view: press Settings…, find iPhone / iPad, tick Let my iPhone/iPad open this window and press Restart. Then open Settings… again, point the iPhone camera at the QR code and tap the link that pops up (no typing; the computer and iPhone must be on the same Wi-Fi/hotspot). Copy address is there too. On Windows, allow the firewall question for private networks. Or simply email yourself the map.

9. Finding the noise source

  1. Drive a wide area with a low band (such as 0.75 or 3.7 MHz) and one VHF channel. Low bands show the general neighborhood; VHF is more local.
  2. Make the map and look for the reddest area. Use Hottest spots to jump to the top places.
  3. Drive that area again, slowly, on every nearby street, and make a second map. The peak should narrow to a block or a pole.
  4. Check the car. If readings stay high everywhere, the noise may be from the vehicle. Move the antenna, or test in a known-quiet place.
  5. Finish on foot with your handheld and yagi. An AM mode works better than FM for tracking noise: an FM receiver is built to ignore the amplitude noise that AM shows. Aircraft-band AM (118–137 MHz) on a clear channel is a good choice.
  6. Note the pole number or address and report it to the utility with your map (Print / PDF or Email).

10. Accuracy and calibration

  • Position: a GPS is typically good to about 10–15 ft, so a dot can sit slightly off the road. Dots consistently 30 ft or more off the road suggest a GPS problem (poor sky view, or a slow-updating GPS in turns).
  • Spacing: a new dot is saved each time you move the spacing distance (default 10 ft; More settings). Measuring four frequencies takes a fraction of a second, so at 45 mph spacing may be a little wider than 10 ft. Fewer frequencies = tighter dots.
  • Levels are relative (dB below the receiver's maximum). The easy way to calibrate is Hardware setup → Slots → Calibrate (type the known level, like -73 or S9). By hand: to get true dBm: feed the receiver a known signal (a signal generator at, say, −60 dBm), note the reading, and enter (known dBm) minus (reading) in that frequency's Calibration box. Keep the same gain settings afterward.
  • Gain and attenuation: automatic gain is always switched off while recording, so readings along the route can be compared. The IF attenuation and RF attenuation numbers (in More settings, and beside the panadapter) set how much the radio is turned down. If readings are stuck near the top or bottom of the scale, or strong stations overload the radio, raise the attenuation before the drive. You can change it while driving if you must, but dots before and after the change are then not directly comparable.

12. Updating, moving, uninstalling

  • Update: run the new version's installer. It replaces the program and keeps your data.
  • Move to another computer: install there, then copy the Drives folder over (or use a backup zip). Maps can be made on any computer, so a Windows PC can make and print maps from drives recorded on the Mac.
  • Uninstall: run Uninstall_RFI_Trail.bat (Windows) or Uninstall RFI Trail (Mac) from the install folder. It shows what is installed and how big your data is, then you choose: 1 remove the program only (your drives, maps and recordings are kept), 2 remove the program and your data (a backup zip is made first), 3 remove everything. On Windows it also removes the shortcuts, Start menu folder and the Windows Settings › Apps entry, and you can uninstall from there too. A record of the uninstall is kept.

About RFI Trail, and thanks

RFI Trail finds radio-frequency interference (power-line and other noise) by logging signal level against your GPS position as you drive, and draws it on a street map. It is the successor to RF Noise Map. Designed and tested on the air by KW4EX. No warranty; use at your own risk.
