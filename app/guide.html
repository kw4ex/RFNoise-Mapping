1. What you need

  • A computer in the car: a Mac or a Windows 11 PC (laptop). It runs the program and does the logging.
  • An SDRplay receiver plugged into that computer, with an antenna mounted away from the engine.
  • A GPS, either:
    • your iPhone with the GPS2IP app (simple; one position per second), or
    • a USB GPS plugged into the computer. A 10-updates-per-second model gives much closer dot spacing at 40–45 mph.
  • The iPhone's Personal Hotspot is handy for internet in the car (needed only to draw the street background when you view a map, and for iPhone GPS).
Why not the iPhone as the whole system? The SDRplay needs a computer driver; it cannot run on an iPhone or iPad. The phone is only the GPS and the hotspot.

2. Download and install

Download (Windows and Mac) — no GitHub account needed

  1. Open github.com/kw4ex/RFNoise-Mapping in your web browser and click Releases (on the right side of the page). Click the newest entry, the one marked Latest. (A Pre-release label means it is still being tested.)
  2. Scroll down to Assets, at the bottom of that page.
  3. Windows: click Install_RFNoise_Windows.bat. Mac: click RFNoise_Mac_….zip. Your browser saves it in your Downloads folder. If it warns that the file may be harmful, choose Keep.
  4. Do not click Source code (zip) or Source code (tar.gz). Those are for programmers.
Windows: you may also click RFNoise_User_Guide.pdf in Assets, the printable copy of this guide.

Mac (experimental: not yet tested on a real Mac by the author)

  1. Open Downloads and double-click the zip you downloaded to unzip it. Keep the folders (mac and app) together.
  2. Open the mac folder. Right-click Install_RFNoise.command and choose Open, then Open again. (Only the first time. macOS asks because the file was downloaded.)
  3. A window explains each step before it does it. Press y and Return to go on.
  4. When it says DONE, an RF Noise Map icon is on your Desktop and in Applications.
If macOS says "cannot be opened because Apple cannot check it for malicious software" (normal for a downloaded file): click Done (never "Move to Trash"). Then either (a) right-click the file, choose Open, then Open again; or (b) open System Settings → Privacy & Security, scroll down to the message about the file, click Open Anyway and enter your Mac password. You only need to do this for the installer; it then clears the warning for the other files in the folder (including the uninstaller).
If the file opens in a text editor, or says it cannot run: open Terminal, type bash (with a space), drag the install file into the Terminal window, press Return.

Windows 11

  1. Double-click Install_RFNoise_Windows.bat (the file you downloaded; keep it anywhere, for example your Downloads folder). If Windows says "Windows protected your PC", click More info then Run anyway.
  2. A window asks which folder to use. Press Enter to accept C:\RadioScripts, or type another. The program makes its own subfolder, RFNoise, inside it, so everything lives in C:\RadioScripts\RFNoise.
  3. It explains each step and asks short questions (answer y or n). It finds Python and offers to install it if missing, and no administrator password is needed.
  4. When it says All done, start the program with Start_RFNoise.bat in that folder, or the Desktop shortcut if you chose one.
The installer saves a copy of everything it said in install_log.txt inside the RFNoise folder. If anything goes wrong, send that file to Claude.

3. The radio driver (SDRplay)

The SDRplay driver is not mine to include; it comes from sdrplay.com. Without it, Practice mode and all map features still work, and you can make maps from drives recorded on another computer.

Mac

  1. Run the installer again and answer y at STEP 3. It opens the SDRplay page; download the macOS API installer and run it. Restart the Mac.
  2. Run the installer once more and answer y at STEP 3. It installs the helper tools (it will offer to install Homebrew, a standard Mac tool installer; it asks for your Mac password) and builds the SDRplay driver module.
  3. Newer driver modules need SDRplay API 3.15 or later. If the build fails, update the API from sdrplay.com and try again.

Windows

  1. SDRplay driver: run the installer again and answer y at the radio step (or go to sdrplay.com → Downloads → Windows) and install the API. Restart if it asks.
  2. Radio library: the program also needs PothosSDR, a free Windows bundle (download link on github.com/pothosware/PothosSDR/wiki). Install it with the default choices.
  3. Open RF Noise Map, plug in the SDRplay, and press Check setup.
  4. Python version: PothosSDR's Python part is made for ONE Python version (currently Python 3.9). The installer notices this, uses (or installs) the matching Python by itself, and sets up the launcher files to use it. If you install PothosSDR later, run the installer again so it picks the right Python.
  5. Close other SDR programs (SDRuno, SDRconnect, SDR Console, HDSDR ...) before you start: only one program can use the radio at a time. RF Noise Map shows a yellow box with a Close them for me button if it sees one.
  6. For a complete automatic check, double-click Test_Everything.bat (or press Full test in the window). It takes about a minute and tests the radio, the GPS and a pretend drive.
Press Check setup any time. It says in plain English what is working and what is missing.

4. First try (no hardware)

  1. Open RF Noise Map (double-click the icon). A window opens in your web browser.
  2. Press Try a practice drive + map in the Tools box. A fake drive is recorded in a second and a map opens: a red stretch is a pretend noisy power pole.
  3. Or tick Practice mode in box 1 and press Start logging to watch the live readings for about 40 seconds.

The practice route is made up, so it won't follow real streets. Real drives will.

5. Connect the GPS

Option A: iPhone

  1. On the iPhone, install GPS2IP from the App Store. A free GPS2IP Lite lets you try it; the full version (a few dollars) is the one to use.
  2. Turn on Personal Hotspot on the iPhone (Settings → Personal Hotspot). Join the computer to that Wi-Fi.
  3. Open GPS2IP and switch it on. Use the fastest update rate (1 second). Make sure the Sockets option is on. Leave the app open.
  4. The app shows an address and a port. In RF Noise Map choose iPhone and type them in. (172.20.10.1 and 11123 are the usual values.)
  5. Press Check setup, tick Also listen to the GPS, and look for a green ✓ with your position.
The iPhone updates once per second. At 45 mph that is about 66 ft between true GPS fixes, so the program slides the position forward along your direction of travel. This works well on straight roads and is less exact in sharp turns.

Option B: USB GPS

  1. Plug it into the computer. In RF Noise Map choose USB GPS and press Find my GPS. It listens on every likely COM port at the common speeds (4800, 9600, 38400, 115200) and fills in the right Port and Speed for you. (Or double-click Find_GPS.bat.) Many pucks use 4800, not 9600.
  2. If it says the port is in use, another program has it open: close other GPS or mapping programs, or unplug the puck for 5 seconds and plug it back in. A new puck often needs a few minutes outdoors for its first position fix.
  3. Press Check setup, tick Also listen to the GPS, and look for a green ✓.
  4. Most pucks come set to 1 update per second. For about 10 ft spacing at 45 mph you want one set to 10 updates per second (a one-time setting). Ask Claude and we'll do it together.

6. Collect data

  1. In box 1 Collect data, type a Route name (optional, but it makes drives easy to find).
  2. Choose the GPS (iPhone or USB), unless you're in Practice mode.
  3. Enter up to four frequencies in MHz. Suggestions: 0.75 (AM broadcast band, wide area), 3.7 or 7.3 (ham bands), and a VHF channel such as 148 or an AM airband channel (118–137) for pinpointing.
    • Pick a quiet channel with no station on it. A pilot's transmission on an airband channel would look like a hot spot.
    • Width is the slice measured (5–10 kHz is good). Narrow slices ignore nearby stations.
    • Leave Calibration at 0 unless you've calibrated (section 10).
  4. Press ▶ Start logging. The header shows Logging and GPS: OK, and the big numbers show the live level for each frequency.
  5. Drive the route. Steady speed is best. You can change frequencies while driving: edit the boxes and press Apply frequency changes now. Pause / resume is there for stops.
  6. Press ■ Stop logging when finished. If Make a map automatically is ticked, the map opens.
Good habits: don't change gain mid-route; keep the computer plugged in (the program keeps it awake while logging); drive each important road twice, once in each direction; note the date and conditions in Name / notes.
Safety: have a passenger operate the computer, or set everything up while parked. Please don't use the screen while driving.

Panadapter: see and hear the band, then pick your frequencies

The Panadapter box (just below Collect data) is a live picture of a slice of the radio spectrum, like the display on a ham SDR. The top picture shows signal strength for every frequency in view; the coloured picture below it is the waterfall, which scrolls so you can see signals come and go over time.

  1. Press ▶ Start panadapter. Allow sound if the browser asks. (It cannot run while logging, because the radio can only do one job at a time. Starting a log closes it automatically.)
  2. Pick a band in Jump to band, or type a Centre frequency in MHz. Width of view is how much spectrum you see (250 kHz to 8 MHz). The grey edges of the picture are less accurate.
  3. Click a signal to tune to it and hear it. The red line is the tuned frequency and the red band is the receiver filter. The mouse wheel changes frequency one Step at a time, or type a frequency in Tuned.
  4. Choose the Mode (AM, USB, LSB, CW or narrow FM) and the Bandwidth of the filter, as on any ham radio. The small green picture shows the audio you are hearing. Use Squelch to silence the audio when nothing is there.
  5. To measure a frequency while driving, press Mapping frequency 1–4. The tuned frequency replaces that slot in the list in box 1. Pick a quiet one with no stations.
The level shown is dBFS, not calibrated. It is good for comparing places, not for absolute measurements. Leave Automatic radio gain on while listening; mapping always uses fixed gain.

7. Where your data is stored

Everything you create is in one folder: on a Mac, the RF Noise Map folder in your home folder (not inside Documents: macOS blocks programs from Documents); on Windows, the install folder itself (normally C:\RadioScripts\RFNoise). The window's footer shows its exact path, and Open my data folder opens it.

FolderWhat is in it
DrivesOne .csv file per drive (opens in Excel / Numbers). Each row: time, latitude, longitude, speed, frequency, level. A small .meta.json beside it holds the name and notes.
MapsFinished maps: one .html file each. Works by double-click in any browser.
ExportsGoogle Earth .kml files, and the .zip files made for emailing.
BackupsZip backups made by the Back up everything button.
SettingsYour remembered choices and the logger's log file.

The program itself is kept apart from your data (Mac: Applications / RF Noise Map; Windows: the app folder inside RFNoise), so you can reinstall or update it without touching your data.

Level numbers: readings are in dB relative to the receiver's maximum (so they're negative; closer to zero = stronger). They compare places perfectly well. See section 10 for true dBm.

8. Make, view, print, save and email maps

Make a map

  1. In box 2 Your recorded drives, press Make map on a drive. The map opens in a new browser tab.
  2. To combine several drives on one map, tick them and press Make map from ticked drives.

Read the map

  • Blue dots = weak, red dots = strong. The color bar shows the dB numbers; change Min / Max to stretch the colors, or press Auto.
  • Pick the frequency in the drop-down. Each frequency has its own picture of the same route.
  • Tap a dot to see its level, time and speed. Hottest spots lists the ten strongest places; tap one to zoom there.
  • The button at top right switches Street / Satellite. Zoom in to separate dots.

Print or save as a PDF

In box 3 Maps press Print / PDF (or the Print / Save as PDF button on the map itself). The print preview shows the title, color scale, strongest spots and the map. Choose your printer, or Save as PDF as the destination. Landscape paper works best.

Save a viewable file

Each map is already a file in Maps folder of your data folder (section 7). Save a copy downloads another copy anywhere you like. Double-click it any time to view it again. It needs internet only for the street background.

Email a map

  1. Press Email beside the map. Type an address (optional) and keep Put the map in a .zip ticked (many email systems block .html attachments).
  2. Press Create email. Your email program opens with the file attached; check it and press Send.
  3. If your email program can't be controlled automatically (some web-based or newer mail apps), a blank email opens and the file is shown in a folder: drag it into the email. The person receiving it unzips it and opens the map in any browser.

Other extras

  • Google Earth: Google Earth beside a drive creates a .kml file with the colored dots (in Exports). Open it with Google Earth.
  • Spreadsheet: Save CSV gives the raw data for Excel / Numbers.
  • Name / notes: add a name and notes (weather, antenna, what you were looking for).
  • Back up everything: one zip of Drives, Maps and Exports in the Backups folder.
  • iPhone / iPad view: tick Let my iPhone/iPad open this window, quit and reopen, then open the address shown on the iPhone (same Wi-Fi/hotspot). On Windows, allow the firewall question for private networks. Or simply email yourself the map.

9. Finding the noise source

  1. Drive a wide area with a low band (such as 0.75 or 3.7 MHz) and one VHF channel. Low bands show the general neighborhood; VHF is more local.
  2. Make the map and look for the reddest area. Use Hottest spots to jump to the top places.
  3. Drive that area again, slowly, on every nearby street, and make a second map. The peak should narrow to a block or a pole.
  4. Check the car. If readings stay high everywhere, the noise may be from the vehicle. Move the antenna, or test in a known-quiet place.
  5. Finish on foot with your handheld and yagi. An AM mode works better than FM for tracking noise: an FM receiver is built to ignore the amplitude noise that AM shows. Aircraft-band AM (118–137 MHz) on a clear channel is a good choice.
  6. Note the pole number or address and report it to the utility with your map (Print / PDF or Email).

10. Accuracy and calibration

  • Position: a GPS is typically good to about 10–15 ft, so a dot can sit slightly off the road. Dots consistently 30 ft or more off the road suggest a GPS problem (poor sky view, or a slow-updating GPS in turns).
  • Spacing: a new dot is saved each time you move the spacing distance (default 10 ft; More settings). Measuring four frequencies takes a fraction of a second, so at 45 mph spacing may be a little wider than 10 ft. Fewer frequencies = tighter dots.
  • Levels are relative (dB below the receiver's maximum). To get true dBm: feed the receiver a known signal (a signal generator at, say, −60 dBm), note the reading, and enter (known dBm) minus (reading) in that frequency's Calibration box. Keep the same gain settings afterward.
  • Gain: automatic gain is switched off so readings along the route can be compared. If readings are stuck near the top or bottom of the scale, adjust IF gain reduction in More settings before the drive.

12. Updating, moving, uninstalling

  • Update: run the new version's installer. It replaces the program and keeps your data.
  • Move to another computer: install there, then copy the Drives folder over (or use a backup zip). Maps can be made on any computer, so a Windows PC can make and print maps from drives recorded on the Mac.
  • Uninstall: run Uninstall_RFNoise.bat (Windows) or Uninstall RF Noise Map (Mac) from the install folder. It asks before it touches your recorded drives and maps, and keeps them unless you say yes.
